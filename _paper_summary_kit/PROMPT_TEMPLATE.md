# Prompt Template For Structured Summaries

このファイルは **人間が読むためのファイル** です。  
ここに書かれているのは、**Codex などのようにリポジトリ全体を見通せる AI** に特定のテーマや資料についてのまとめの生成を依頼するときの、

- 下準備
- 投げるプロンプトのテンプレ
- 期待する出力

です。

AI が要約を作る際の仕様は `_paper_summary_kit/README.md` と `_paper_summary_kit/STYLE_GUIDE.md` にあります。

**1プロンプト + 資料だけで作らせる standalone 用テンプレは、このファイルには書きません。必要なら `_paper_summary_kit/STANDALONE_PROMPT.md` を見てください。**

## 下準備

1. `_summaries/` の中に、要約したいテーマ専用のフォルダを作る
2. 参考にさせたいファイルがある場合は、そのフォルダに入れる
3. 参考にさせたいファイルがない場合でも、そのフォルダが作業単位として使われる
4. AI にその作業フォルダのパスを下記のプロンプトと共に渡す。

期待する結果:

- AI はその作業フォルダをもとにまとめを作る
- 出力は同じ作業フォルダ内の `.json`
- JSON ファイル名は作業フォルダ名と同じ名前

## プロンプト

必要に応じて、何についてのまとめか、どういうテイストでまとめてほしいかは自分で書き足してください。

### 資料ありのとき（必要に合わせて何についてのまとめか、どういう知識想定で生成するかの指定は書き加えてください）

このリポジトリ全体を読んでよいです。  
`_paper_summary_kit/README.md` と `_paper_summary_kit/STYLE_GUIDE.md` に従って、次の作業フォルダ内の資料をもとに QAmatomer 用の JSON まとめを作ってください。  
数式がある場合は、インライン数式を `$...$`、別行立ての数式を `\[ ... \]` で必ず囲ってください。裸の数式や Unicode 数学記号のまま書かないでください。  
出力は同じ作業フォルダ内の `.json` にしてください。ファイル名は、作業フォルダ名と同じ名前にしてください。

作業フォルダ:

- `_summaries/ここにフォルダ名`

### 資料なしのとき（必要に合わせて何についてのまとめか、どういう知識想定で生成するかの指定は書き加えてください）

このリポジトリ全体を読んでよいです。  
`_paper_summary_kit/README.md` と `_paper_summary_kit/STYLE_GUIDE.md` に従って、次の作業フォルダを使って QAmatomer 用の JSON まとめを作ってください。  
今回は作業フォルダ内に資料を置いていないので、そのテーマについて追加で調べた情報も使ってまとめを作ってください。  
数式がある場合は、インライン数式を `$...$`、別行立ての数式を `\[ ... \]` で必ず囲ってください。裸の数式や Unicode 数学記号のまま書かないでください。  
出力した JSON まとめは同じ作業フォルダ内に生成してください。ファイル名は、できれば作業フォルダ名と同じ名前にしてください。

作業フォルダ:

- `_summaries/ここにフォルダ名`

## 追加質問を後から追記したいとき

まとめを作った後、個別に質問して得た回答を既存の JSON に `qa` セクションとして追記したい場合。

```text
このリポジトリ全体を読んでよいです。
次の作業フォルダにある既存の JSON まとめに Q&A を追記してください。
root の children に `qa` という section node を追加し（すでにある場合は既存の leaf を残したまま）、質問ごとに leaf を 1 つずつ追加してください。
数式がある場合は、インライン数式を `$...$`、別行立ての数式を `\[ ... \]` で必ず囲ってください。

作業フォルダ:
- _summaries/ここにフォルダ名

追加する質問:
- Q: （質問をここに書く）
```

## 既存まとめを修正したいとき

既存の JSON まとめを修正したい場合は、そのファイルが入っている作業フォルダを AI に渡す。

例:

- `_summaries/ここにフォルダ名`

そのうえで次のように依頼する。

```text
このリポジトリ全体を読んでよいです。
_paper_summary_kit/README.md と _paper_summary_kit/STYLE_GUIDE.md に従って、次の作業フォルダにある既存の JSON まとめを整理し直してください。
数式がある場合は、インライン数式を `$...$`、別行立ての数式を `\[ ... \]` で必ず囲ってください。

作業フォルダ:
- _summaries/ここにフォルダ名
```
